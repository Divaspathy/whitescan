# 🛡️ WhiteScan

**Automated Network Reconnaissance & Vulnerability Assessment Tool**

WhiteScan is a Python-based security assessment toolkit that automates network discovery, port scanning, service enumeration, and vulnerability assessment using ARP discovery, Nmap, and OpenVAS (GVM).

## 🚀 Features

- ARP-based network host discovery
- Automated Nmap port and service scanning
- OpenVAS / GVM vulnerability assessment integration
- Automated reconnaissance workflow
- Configurable scanning options
- Command-line interface

- Linux (Kali Linux recommended)
- Python 3
- Nmap
- OpenVAS / GVM (optional, for vulnerability scanning)
